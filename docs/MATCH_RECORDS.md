# 对局战绩

完整结算时，服务端按房间保存一条战绩，包含每位玩家的输出及占比、盟约逐项层数、商店购入卡牌的名称、数量、花费与各回合次数等。中途退出或服务关闭不产生完整战绩。旧版本从未持久保存的对局无法补录。

- 大厅中的「上局战绩」展示自己的最近一局；房间内的按钮优先展示该房间的最近一局，并列出全部队友。浏览器也保留本机最近一次收到的结算，供重连后查看。
- `GET /api/records/ABCD` 返回房间 `ABCD` 最近一次完整对局的公开数据；没有记录返回 404。房间号多次开局时默认取最近一局，不公开玩家会话 ID。知道房间号的人可以查到该房间战绩，不应把房间号视作私密凭证。
- 服务端日志保存在 `var/match-records.jsonl`，或由 `SP_RECORDS_FILE` 指向独立的持久化目录。升级部署时必须保留此文件；重启后会重新加载。
- 黍的 AstrBot 插件位于 `integrations/astrbot_sp_records`。安装到 AstrBot 的 `data/plugins/astrbot_plugin_sp_records` 后，在群聊发送 `@黍 战绩 ABCD`，机器人会发送一张总览和逐人盟约、购卡明细卡。插件需要 Pillow，并通过正式服域名读取公开战绩接口。

代号由客户端和服务端共同拦截：纯数字、`test`、`admin` 与三位以上纯 `a`（大小写不敏感）均不可使用。
