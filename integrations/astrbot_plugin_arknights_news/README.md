# 明日方舟公告 v2

监控明日方舟官网情报中心，默认每 10 分钟检查。首次只建立基线，不补发历史公告。

- 黑白黄情报档案卡片，固定 1600×900（16:9），44px 标题、32px 正文；所有分页同尺寸同版式，长公告只分页、不缩字，末页不缩高。
- 使用官网明日方舟和罗德岛 Logo，卡片标注官网来源及自动整理，非官方插件。
- 有正文配图或多页正文时，以一条 QQ 合并转发发送：来源链接、正文卡片、官网原图。单页纯文字公告发送一张卡片附链接。
- 配图加载失败在转发中保留原图链接；转发失败不散图刷屏，保留待重试状态。最多 90 个常规节点，超出配图明确引导官网查看。
- 仅支持 QQ OneBot 主动推送。未绑定目标时不会主动发群消息。
- 新公告向群聊成功投递后，用真实 `@全体成员` 组件伴随分类提示发送一次；私聊及 `/方舟公告测试` 不 @全体。全体提醒因权限或额度失败时只尝试普通文字提示，不重新投递公告或反复 @全体。
- 每条公告伴随一次固定提示，不调用模型：普通公告“叮叮~明日方舟有新公告出炉啦！”；标题含“制作组通讯”时优先用“发现新的制作组通讯，请查收~”；活动分类或活动标题用“博士，有新活动诶！一起来看看吧~~”。正常推送在内容投递后单独发送提示，分页和原图不重复提示；手动测试保留普通提示，不 @全体。
- 管理员命令：`/方舟公告绑定`、`/方舟公告解绑`、`/方舟公告检查`、`/方舟公告测试`。状态查询：`/方舟公告状态`。
- `target_umos` 可在 AstrBot 插件配置中填写；配置目标需在配置中删除，绑定命令添加的目标可用解绑命令删除。
- 旧卡片样式后台默认关闭；新版固定视觉方案不使用旧样式参数，不要开启旧后台调整新版卡片。
